Instalar node js
https://nodejs.org/en/download

luego de haberlo instalado hay que ejecutar estos comandos que inicia npm en el proyecto
npm init -y
m
y pues instala las dependencias necesarias como express, multers, cors
express es el encargado de crear el servidor y las rutas, multer para la subida de los documentos adjuntos y cors permite la comunicacion del frontend con el backend 

npm install express multer cors

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
